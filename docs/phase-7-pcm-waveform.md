# Phase 7: measured PCM audio waveform workspace

## Implemented

The Media analysis page now has **Open WAV waveform** for uploaded Audio artifacts. The service checks the registered SHA-256 and reads actual PCM samples. The viewer shows a min/max amplitude envelope, RMS envelope, numeric peak/RMS values, full-scale sample count, native audio playback, pointer time/value inspection, and a keyboard-accessible time slider.

Cyan and purple distinguish measured signal tracks. They are not authenticity or detector-confidence colours. No deepfake flags are generated.

## Use

1. Open `http://127.0.0.1:8100/#media`.
2. Select uploaded 8-bit or 16-bit uncompressed PCM WAV audio.
3. Choose **Open WAV waveform**.
4. Hover over the plotted envelope for time-bin min/max/RMS values. Click to seek, or use the labelled slider with the keyboard.
5. Use native audio controls to play/pause. Playback stops when navigating to another page or changing the selected artifact.

The display scales the envelope to make quiet files readable and shows its gain. This changes only plotted geometry; measurements and source audio stay unchanged.

## API and bounds

- `GET /api/v1/cases/{caseId}/artifacts/{artifactId}/waveform`: measured envelope and signal summary.
- `GET /api/v1/cases/{caseId}/artifacts/{artifactId}/audio-preview`: original WAV with byte-range support.
- Case-scoped upload lookup and resolved path containment.
- Waveform inputs limited to 64 MB, eight channels, 8/16-bit PCM, sample rates up to 384 kHz, and nonempty data.
- At most 256 time bins, combining all channels. Every bin reads its corresponding sample frames; values are not random or generated by a model.
- Streaming pre/post extraction hashes, declared frame/data bounds, truncated-data detection, and one active media operation per API process.
- Unsupported formats and integrity mismatches return explicit errors. Fixture filenames without uploaded bytes have no waveform.

The PCM reader uses Python's standard library. No new service, dataset, model, or download was added. Waveforms are computed on request and not persisted as agent memory in this phase.

Measured results: `output/phase7-verification.json`. Run `python scripts/verify_phase7.py` after the Phase 5 synthetic fixture has been uploaded.

## Remaining scope

This is an amplitude envelope, not a spectrogram, per-sample oscilloscope, transcription, or authenticity detector. Full-scale samples do not by themselves establish clipping, editing, or manipulation. MP3/AAC, video audio extraction, channel-isolated tracks, zoomable higher-resolution bins, saved annotations, and model-based detection remain later work. The application remains a local development service without production identity or case authorisation.
